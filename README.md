# SalesPulse – Sales Dashboard

An interactive sales analytics dashboard built for the Front-End Final Assessment.

## Features
- Sales data for 2022, 2023 and 2024 (sample/mock dataset)
- KPI cards for revenue, orders, customers and average order value
- Monthly revenue visualizations with Bar, Line and Pie chart views
- Year selector and custom minimum-revenue filter
- Export filtered records to CSV
- Responsive dashboard layout

## Tech stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Recharts
- Lucide React

## Run locally
1. Install Node.js 20 or later.
2. Extract this project and open its folder in VS Code.
3. Open the terminal in this folder and run:

   ```bash
   npm install
   npm run dev
   ```

4. Visit http://localhost:3000

## Build
```bash
npm run build
```

## Data note
The included dataset is mock/sample data created for demonstration and assessment purposes. It is not live company sales data.
